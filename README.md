# Mockup para o WebApp do Grupo de Capoeira Beribazu

Aplicação web desenvolvida em Python com Flask para exibir e reproduzir filmes, séries e TV ao vivo através de uma API externa. Interface inspirada no Netflix.

## Características

- **Home Page**
- **Lista de Eventos**: Grade eventos dos CTs
- **Lista de Centros de Treinamento**: Grade CTs espalhados pelo Brasil para facilitar a busca
- **Painel Admin**: Área administrativa para membros docentes e alunos

## Tecnologias Utilizadas

- **Backend**: PHP 8.4, Mysql, Docker
- **Frontend**: HTML5, CSS3, JavaScript, jQuery
- **API**: Integração com API do Google Maps

## Como Executar

1. Execute a aplicação:
```bash
docker compose up -d --build
```

1. Acessar a seguinte url:
```bash
localhost:8072
```
